# بهبود فونت و راست‌چین کردن سایت‌های مشخص

## توضیحات فارسی

این اسکریپت تمپرمانکی برای بهبود نمایش فونت و راست‌چین کردن محتوای چندین سایت کاربردی طراحی شده است.

### ویژگی‌ها:
- **بهبود فونت**: استفاده از فونت‌های زیبای فارسی/عربی از Google Fonts
- **راست‌چین کردن**: اعمال خودکار RTL برای سایت‌های پشتیبانی شده
- **استایل‌دهی هوشمند**: تفکیک استایل برای تیترها، متن معمولی، بولد، ایتالیک و کد

### سایت‌های پشتیبانی شده:
- Gemini (gemini.google.com)
- ChatGPT (chatgpt.com)
- Todoist (app.todoist.com)
- Grok (grok.com)
- DeepSeek Chat (chat.deepseek.com)
- Google Keep (keep.google.com)
- Claude AI (claude.ai)

### فونت‌های استفاده شده:
- **Rubik**: فونت اصلی برای متن‌های معمولی
- **Lalezar**: برای تیترهای H1
- **Noto Nastaliq Urdu**: برای متن‌های بولد در تیترها
- **Baloo Bhaijaan 2**: برای تیترهای H2 و متن‌های بولد
- **Cairo Play**: برای متن‌های بولد دیگر و کدها
- **Handjet**: برای متن‌های ایتالیک

---

## English Description

This TamperMonkey script improves font rendering and applies right-to-left (RTL) layout for several useful websites.

### Features:
- **Font Enhancement**: Beautiful Persian/Arabic fonts from Google Fonts
- **RTL Support**: Automatic right-to-left layout for supported sites
- **Smart Styling**: Separate styles for headings, normal text, bold, italic, and code

### Supported Websites:
- Gemini (gemini.google.com)
- ChatGPT (chatgpt.com)
- Todoist (app.todoist.com)
- Grok (grok.com)
- DeepSeek Chat (chat.deepseek.com)
- Google Keep (keep.google.com)
- Claude AI (claude.ai)

### Fonts Used:
- **Rubik**: Main font for regular text
- **Lalezar**: For H1 headings
- **Noto Nastaliq Urdu**: For bold text in headings
- **Baloo Bhaijaan 2**: For H2 headings and bold text
- **Cairo Play**: For other bold text and code blocks
- **Handjet**: For italic text

## نصب / Installation

1. افزونه TamperMonkey را روی مرورگر خود نصب کنید
2. روی لینک فایل `.user.js` کلیک کنید
3. دکمه Install را بزنید

Install TamperMonkey extension on your browser, then click the `.user.js` file and press Install.
