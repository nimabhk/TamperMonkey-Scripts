# Tampermonkey Scripts Bucket 📦

A collection of ready-to-install Tampermonkey user scripts organized by category.

**Author**: Nima Behkar ([nimabhk](https://github.com/nimabhk))

## Categories 📁

- [Social Media](categories/social-media/) - Scripts for social media platforms
- [E-commerce](categories/e-commerce/) - Scripts for online shopping and e-commerce sites
- [Developer Tools](categories/developer-tools/) - Scripts for developers and coding
- [Entertainment](categories/entertainment/) - Scripts for streaming and entertainment sites
- [Productivity](categories/productivity/) - Scripts to boost productivity
- [Security & Privacy](categories/security-privacy/) - Scripts for security and privacy enhancement
- [Automation](categories/automation/) - Automation scripts for various tasks
- [UI/UX](categories/ui-ux/) - Scripts for UI/UX improvements

### Available Scripts

#### UI/UX
- [Font Fix & RTL Support](categories/ui-ux/font-fix-and-rtl-0.5.user.js) - Improve fonts and apply RTL for Gemini, ChatGPT, Todoist, Grok, DeepSeek, Google Keep, and Claude AI

## Installation 🔧

1. Install [Tampermonkey extension](https://www.tampermonkey.net/) for your browser
2. Click on any `.user.js` file in the categories folders
3. Tampermonkey will open and prompt you to install the script
4. Click "Install" and you're done!

## Usage 💡

Each script comes with a corresponding `.md` file that explains:
- What the script does
- How to use it
- Any configuration options

## نصب 🔧

1. افزونه [Tampermonkey](https://www.tampermonkey.net/) را روی مرورگر خود نصب کنید
2. روی هر فایل `.user.js` در پوشه‌های دسته‌بندی کلیک کنید
3. تمپرمانکی باز می‌شود و پیام نصب اسکریپت را نمایش می‌دهد
4. روی "Install" کلیک کنید و تمام!

## استفاده 💡

هر اسکریپت یک فایل `.md` همراه دارد که توضیح می‌دهد:
- اسکریپت چه کاری انجام می‌دهد
- نحوه استفاده
- گزینه‌های پیکربندی (در صورت وجود)
